
# Crime Rate Analysis and Prediction Using Machine Learning

## Project Overview
This project focuses on analyzing historical crime statistics and predicting violent crime rates using machine learning.

## Dataset
Source: Maryland Open Data Portal

Dataset: Violent Crime and Property Crime by County (1975–Present).

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- IDLE

## Data Preprocessing
- Dataset exploration
- Missing value handling
- Feature engineering
- Previous-year crime rate calculation
- Training and testing split

## Machine Learning Models
1. Linear Regression
2. Polynomial Regression
3. Decision Tree Regression
4. Random Forest Regression
5. Support Vector Regression

## Evaluation Metrics
- MAE
- MSE
- RMSE
- R-squared Score
